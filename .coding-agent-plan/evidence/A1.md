## Implementation

- Agents `25014203d4bc92ac74b30c3ac9fecd941f78180e` removes repository-local Coding Agent state. Runs, sessions, artifacts, process ledgers, patch journals, and trust records now live under a dedicated private user-state root at `workspaces/<canonical-workspace-id>`.
- The default is `$XDG_STATE_HOME/coding-agent` when `XDG_STATE_HOME` is absolute, otherwise the platform home state location. `--state-root` selects a dedicated alternative.
- State roots are accepted only when empty or carrying the exact v1 Coding Agent marker, reject aliases and non-directories, enforce private POSIX modes, publish atomically, and cannot be located inside the workspace. No `.coding-agent` data is read as application state; that name is denied to generic workspace tools.
- The application adopts `WorkspaceFileRoot` once. The exact capability supplies canonical identity, configuration reads, instruction reads, and all file tools before ownership transfers to `LocalToolHost`.
- `coding-agent trust status|restricted|trusted|revoke` is the only CLI trust transition. A missing/revoked/identity-changed record is untrusted and blocks provider/runtime construction.
- `coding-agent.config.json` is discovered when present or selected with `--config`, read through the root capability with an exact post-read identity check, parsed once, and retained with source URI, SHA-256, and trust provenance.
- Restricted project configuration may narrow enabled tools and authorization and supply attributed guidance. It cannot select the provider/model, activate command checks, or install resource limits. Trusted configuration may be activated within the invocation ceiling.
- Provider/model precedence is explicit invocation, matching resumed session, trusted project configuration, then environment. The former hidden Ollama/provider-model defaults were deleted; missing setup is an explicit error.
- Runtime metadata captures workspace identity/trust and project configuration source/hash/trust. It no longer sends the absolute workspace root as provider metadata.
