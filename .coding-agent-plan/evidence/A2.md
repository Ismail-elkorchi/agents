# A2 evidence

Status: done

- Agents `5f53304abb36c2933ec2e55ebae0782b01818337` adds a coding-specific default contract, bounded hierarchical `AGENTS.md` discovery, explicitly configured instruction sources, exact source hashes and scopes, deterministic root-to-leaf precedence, visible terminal/bidi hazards, bounded manifest summaries, and verification-command proposals that remain inert data.
- The initial orientation reveals only the adopted workspace identity, trust state, bounded package metadata, instruction provenance, and a Git/non-Git marker. It does not eagerly enumerate the repository.
- A hostile repository experiment confirmed that `git status` can execute a repository-defined `filter.<driver>.clean` or `process` command selected through `.gitattributes`; Git can also invoke configured filesystem monitors. Disabling hooks, prompting, textconv, and selected configuration names does not provide a complete non-execution guarantee because local configuration and include graphs remain an execution authority.
- Therefore A2 deliberately performs no host-side Git command. A Git marker reports `sandbox_required`; G0 owns the exact sandbox-backed branch and dirty/untracked observation after S0. This replaces the original overbroad “sanitized Git” acceptance criterion rather than pretending an incomplete configuration deny-list is safe.
- Repository configuration paths are bounded and unique. Discovered aliases are omitted and explicitly configured aliases fail. Instruction content cannot grant tool, provider, sandbox, or trust authority.
