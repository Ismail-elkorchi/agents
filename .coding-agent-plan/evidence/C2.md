# C2 evidence

Status: done

- Agent Core now defines the domain-neutral `CommandExecution` behavior contract for start, cursor-based query, input, termination, run cleanup, authenticated recovery reports, reconciliation, implementation identity, recovery-store identity, capabilities, and resource-lease ownership.
- `adoptCommandExecution(unknown)` validates an adapter once. Later `isCommandExecution()` checks package-owned admission rather than structurally re-proving or using `instanceof`. Immutable descriptors prevent identity or capability mutation after admission.
- The old public `ProcessManager`, `processManager` service key, concrete runtime probes, and historical method names were deleted. `LocalCommandExecution` is the explicit ambient Node implementation; tools and runtime consume only `CommandExecution`.
- Command requests use canonical workspace-relative paths. The local implementation owns physical directory resolution through an adopted `WorkspaceFileRoot`; sandbox adapters therefore do not receive ambient host paths.
- The root-bound command directory now uses a held parent-process descriptor path. A live path-swap test renames the admitted directory and replaces its old pathname with an outside symlink before command release; the command writes only into the retained physical directory.
- Recovery identity binds the exact local ledger directory and adopted physical workspace identity. Process IDs remain unpredictable, ownership checks reject other runs, reconciliation requires authenticated supervisor identity, and unresolved recovery blocks all new commands for that authority.
- Provider-unknown suspension was found to omit command cleanup. Every recovery suspension now disposes owned commands before publication and reports cleanup failure without inventing provider settlement.
- The C2/S0 wording was narrowed to remove an impossible dependency cycle: C2 establishes and tests the shared contract against the local implementation; S0 cannot begin until C2 is done and must run equivalent conformance against the sandbox adapter.
- `npm run verify:release` passed in Agent Core, including 328 unit tests, 152 focused tests, lint, build, and packed-consumer checks.
