## Implemented contract

- Coding Agent observes Git only through `SandboxGitRepositoryObserver`. It resolves one exact Git executable, admits a read-only/no-network Sandbox run, disables prompting and optional locks, supplies an inert system/global/local command policy, and never falls back to a host subprocess.
- Git-specific authority stays in Coding Agent. Sandbox receives only a process and filesystem policy; Agent Core receives only the resulting bounded repository orientation.
- Porcelain v2 `-z` output is decoded with fatal UTF-8 handling, bounded to 2 MiB and 2,000 status records, and parsed into branch/head plus attributed untrusted paths. Truncation is explicit rather than silently presented as complete status.
- Linked worktrees, submodule Git directories, and common directories receive exact read-only grants after physical resolution. Bare repositories are recognized and report the absence of a work-tree status without inventing one.
- Observation metadata binds the Sandbox execution identity, request/policy/execution digests, enforcement report, and terminal receipt.
