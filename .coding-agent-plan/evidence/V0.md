# V0 — First resilient CLI slice and stop/go gate

Status: current

- V0 starts from Agents `13c1e1c8c3c0a237e5d60675c35d71561e99719a`, Agent Core `616a50d67bdd82a6691ab8dfcdbf67609460140d`, Sandbox `e82ff3dd94a7c87b14bd25665b8898ae3b081767`, and Terminal UI `d83d01432056470d17f42793bb83f6d7c93e595d`.
- Before product integration, the baseline was restored across the release matrix. Agent Core now distinguishes the Windows process-termination tier from unsupported directory-entry power-loss durability, and non-Linux CI no longer invokes Linux-only root-capability process tests. Agents CI now checks out complete Agents history plus the exact reviewed Agent Core and Terminal UI repositories, and the plan validator proves that package pins equal reviewed heads; a depth-one checkout can no longer masquerade as failed ancestry or omit a repository the validator is required to inspect.
- A final Windows-only flake was traced to a test that coupled an authoritative 12 ms stream-idle timeout to delivery of a best-effort 2 ms status cadence. Agent Core `616a50d67bdd82a6691ab8dfcdbf67609460140d` keeps the timeout contract and removes the invalid scheduling assumption rather than delaying or weakening timeout behavior.
- Agents `13c1e1c8c3c0a237e5d60675c35d71561e99719a` completes CI source materialization by checking out, building, and validating Sandbox as well as Agent Core and Terminal UI. Its generated-ledger check compares canonical content independently of Git's Windows CRLF checkout transformation.
- The gate will compose the existing authorities without adding advanced parallel settlement, TUI work, rollback, or a model-evaluation matrix. Its first work is a deterministic CLI fixture that exercises instruction scope, a root-bound read, one structured mutation, a direct sandboxed command, one required isolated check, process loss, recovery, and the A5 machine report.
- The real-provider case is evidence rather than deterministic CI. Credentials and provider output will not be copied into this ledger.
