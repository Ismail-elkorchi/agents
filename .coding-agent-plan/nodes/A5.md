# A5 — Change accounting and review data

**Intent:** Derive exact review and final-summary facts without requiring first-release undo.

**Work:** Capture the initial dirty/untracked baseline without assuming Git cleanliness. For every structured mutation retain before/after path identity, hashes, operation kind, receipt, instruction/tool cause, and conflicts. Build exact changed-file and patch views from C0 receipts plus sanitized VCS data. Machine fields—not model prose—supply final changed paths and verification status.

**Acceptance:** Preserve pre-existing user changes; distinguish user baseline from agent changes; detect concurrent edits/renames/deletes and changed aliases; report added/deleted/binary/large files and partial diff coverage; reject final claims inconsistent with receipts. No command effect is labelled undoable.

**Deferred C4:** User-requested exact structured undo may be designed after V0/A7 evidence. It must check current hashes, never overwrite later changes, report partial conflicts, and remain a new authorized mutation. It is not a release dependency and no compatibility placeholder is added now.
