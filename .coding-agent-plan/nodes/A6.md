# A6 — TUI and session correctness

**Intent:** Present durable truth without making the TUI an execution authority.

**Work:** Hydrate existing conversation/run/approval/unknown-effect state before live events; use reliable Terminal UI source delivery; surface queue, driver, recovery, check, change, trust, sandbox, and permission state. Remove swallowed dispatch failures, arbitrary reliable-event eviction, dead command effects, and unusable history.

**Acceptance:** Transcript tests cover restore then live append without duplicates, approval, unknown effect, recovered operation, long streaming pressure, command history, focus/resize/tiny bounds, cancellation, dispatch failure, and shutdown. UI actions dispatch application messages only. Framework defects follow T1 immediately rather than receiving local workarounds.
