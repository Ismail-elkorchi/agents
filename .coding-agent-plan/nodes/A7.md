# A7 — Complete coding product loop

**Intent:** Turn the resilient kernel into a competent product.

**Workflow:** understand -> inspect -> plan locally -> mutate -> inspect exact change -> verify -> disposition/revise -> explain. Add CLI/TUI views for changes, active/completed tools, sandbox enforcement, checks, approval boundaries, operation/recovery state, branches, and prior terminal states. Keep plan text product-local and non-authoritative.

**Acceptance:** Real tasks cover bug diagnosis, confined fix, multi-file refactor, dead-code removal, review-only, denied action, dirty worktree, non-Git root, failed-check repair, concurrent file conflict, interrupted/recovered work, malicious repository content, and no-network execution. Every final summary uses A5/A4 facts and names remaining uncertainty.
