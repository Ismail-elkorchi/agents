# C1 — Prepared tool authority lifetime

**Intent:** Ensure denied, aborted, superseded, expired, or unselected prepared calls release authority.

**Work:** Give preparation an explicit lifecycle: prepare -> authorize -> transfer into one effect ticket -> settle/release. Preparation owns any file handles, leases, staged resources, or sandbox preparation until transfer. The driver generation and E0 identity are captured.

**Acceptance:** Exactly-once release across denial, approval suspension, abort, decode/presentation failure, takeover, batch sibling failure, timeout, and success; use-after-release/start rejects; no finalizer dependence; tests use behavior ports rather than concrete implementation identity.
