# C2 — Command execution capability port

**Intent:** Remove concrete `ProcessManager` authority from tools/runtime/application checks.

**Work:** Define a behavior port for start, poll/query, input, terminate, receipt, cleanup, and recovery identity. `tools-local` implements the host-local port for tests and explicitly ambient applications; coding-agent supplies the sandbox-backed implementation through A3. No `instanceof` proof.

**Acceptance:** Shared contract tests run against local and sandbox adapters; ownership and retention are explicit; output/cursor/backpressure limits and cleanup are equivalent where claimed; process IDs cannot be guessed across runs; removing the concrete service does not weaken types.
