# D3 — Parallel completion and source-order projection

**Intent:** Add concurrency only after D2 works end to end.

**Work:** Each call in a batch independently enters intent/start/settled/unknown state and commits its observation immediately on completion. Source-order conversation projection advances only through the contiguous settled prefix. Scheduler/resource dependencies remain explicit.

**Acceptance:** Kill after every completion permutation; settle fast later siblings while earlier calls run; never rerun settled calls; never project gaps; late stale-owner settlements reconcile exactly once; cancellation drains/marks every call; concurrency and budget caps survive restart.
